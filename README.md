# Расчёт заработной платы — Вариант 6

**Курсовая работа по КПО**  
Язык: **Go** | GUI: **Fyne v2** | БД: **SQLite**

**Логин по умолчанию:** `admin` / `admin123`

## Возможности

### Администратор
- Управление сотрудниками: добавить, просмотреть, редактировать, удалить
- Поиск по ФИО или табельному номеру
- Сортировка по любому полю (возр./убыв.)
- Расчёт ЗП за период для конкретного сотрудника
- Управление учётными записями пользователей (CRUD)

### Пользователь
- Просмотр всех данных
- Поиск и сортировка
- Расчёт ЗП за период

## Задача варианта 6

- Часы ≤ 144 — обычная оплата: `часы × тариф`  
- Часы > 144 — сверхурочные оплачиваются ×2  
- Подоходный налог: **12%** от брутто-зарплаты  
- Расчёт выплат за период по конкретному сотруднику
